# 参数化 SQL 与查询模板

在 SQL 工作台用 `:参数名` 表示一个值，点击执行后填写参数，例如：

```sql
SELECT * FROM orders
WHERE customer_id = :customer_id
  AND created_at >= :start_time
```

名称区分大小写，由英文字母或下划线开头，可包含数字，最长 64 个字符。同一个参数重复出现只填写一次。字符串、标识符及普通注释中的冒号不作为参数；PostgreSQL 的 `::` 类型转换保持原样。参数只代表单个值，不可替换表名、列名、排序方向或整段 SQL，也不展开 IN 列表。

## 保存模板

1. 在 SQL 工作台的“更多”中选择“把当前 SQL 保存为片段”，或打开“SQL 片段库”新建。
2. 点击“从 SQL 识别参数”，设置各参数的类型、是否允许 NULL 和默认值。
3. 保存后，列表标记为参数模板。“打开模板”会新建 SQL 标签，保留原标签内容；执行时带出默认值。

模板沿用原有个人/团队共享和编辑权限。修改 SQL 中的参数名后，应重新识别参数；保存时服务端核对参数定义和 SQL 是否一致。默认值保存在模板中，共享模板的可见用户也能看到它，请勿保存密码等敏感值。模板定义随 SQL 草稿恢复；本次填写的参数值不会写进草稿或 SQL 历史。

## 类型与空值

支持文本、64 位整数、精确小数、布尔、日期、日期时间。整数和小数在浏览器中以字符串传输，不经过 JavaScript 浮点数转换。日期使用 `YYYY-MM-DD`，日期时间使用 `YYYY-MM-DD HH:mm:ss`，可带最多九位小数秒，不包含时区。布尔值为 `true` / `false`。

允许 NULL 的参数通过独立复选框选择 NULL。文本空字符串与 NULL 分开处理；目标数据库本身的语义仍生效（例如 Oracle 将空字符串视为 NULL）。`column = :value` 在参数为 NULL 时不会自动改成 `IS NULL`，需要按查询需求编写条件。默认值可以明确设置为空字符串。

执行对话框可以调整本次参数类型，不修改已保存的模板定义。后端再次验证名称和类型，通过 `PreparedStatement` 绑定，参数值不会被拼接进 SQL；审计和 SQL 历史保留带参数名的原语句，失败历史不保存可能包含参数值的驱动错误详情。

## 支持范围

- 只支持单条 SELECT 查询（包括只读 CTE），不支持参数化 DML、DDL、多语句脚本和存储过程调用。
- 复用连接查询权限、生产连接名确认、查询超时、执行取消及结果大小限制。
- 参数查询使用普通执行模式；需先结束手动事务，不支持脚本事务、参数化执行计划。
- 未自带分页子句的查询按工作台页大小进行服务端分页，支持跨页排序筛选；自带 LIMIT/OFFSET 等分页的查询走原有有界执行。SQL Server 的 CTE 查询保留有界执行，避免将 WITH 放入不支持的派生表。参数结果不支持就地编辑。每页仍受服务端行数/单元格/文本预算限制。
- 参数值在结果的内存上下文保留供翻页使用，不进入草稿或 SQL 历史；页面刷新后需重新执行。工作台“导出”会重新填写参数并导出完整查询结果，结果网格“导出当前批次”只导出已加载数据。
- 完整参数导出支持现有六种格式，取消会请求 JDBC 取消；保留查询超时和 256 MiB 文件预算。Excel 有单表行数和单元格限制，现有各格式的大字段读取上限仍生效。“完整”指查询行范围。导出失败不提供部分文件；当前不是可恢复的后台任务。
- 不支持混用 JDBC `?` 占位符或问号运算符，也不支持 MySQL 可执行注释；问号运算符请改写为相应函数形式。
- 新增 V22 元数据迁移，为片段保存参数定义。已有片段内容和权限保持原样，无需修改目标业务库。

参数分页、重复参数、排序筛选与导出已通过 H2、MySQL 8.4、MariaDB 11.4、Oracle Free、DM8、SQL Server 2022 和 OceanBase 4.3.5 MySQL 模式实测。OceanBase Oracle 模式仍待独立租户回归。日期输入验证实际日历日期，小数限制为最多 1000 位有效数字、尺度绝对值不超过 1000；服务端再次校验。导出历史保存 JDBC 占位符语句，审计保留原模板，均不包含本次绑定值。
